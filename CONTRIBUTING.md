# Contribuir a OPoptimizer

¡Gracias por querer mejorar este proyecto!

## Guías básicas

1. Abrí un issue para proponer una función nueva o informar errores.
2. Si modificás código, describí qué cambia y cómo lo probaste.
3. No agregues código que borre carpetas de juegos ni altere servicios de Windows sin una explicación clara, consentimiento y forma de revertirlo.
4. No incluyas telemetría, publicidad, instalación de programas externos ni acciones ocultas.
5. Para nuevas limpiezas, usá una lista explícita de carpetas permitidas, vista previa y confirmación.
6. Probá los cambios en Windows 10 y 11 antes de enviarlos.

El proyecto usa C# / WPF / .NET 8 y licencia MIT.
